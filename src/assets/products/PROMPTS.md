# Product photo prompts

Make each image 3:4 portrait, at least 1200 x 1600. Save it in this folder under the file name shown (jpg, png or webp). Add `-2`, `-3` for extra angles. The site picks them up automatically.

Compare every picture with the real garment before selling it: colour, pockets, print and fit should match.

## Style: paste at the start of every prompt

> Realistic fashion lookbook photograph, adult male model in his mid twenties, calm direct expression, standing against a raw board-formed concrete wall, soft overcast daylight, muted neutral colours, natural skin texture, 50mm lens, full garment visible and centred, no logos, no text, no watermark. Vertical 3:4.

Use one reference face if your tool supports it, so the set looks like one shoot.
